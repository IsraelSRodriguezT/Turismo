# Turismo

Plataforma digital diseñada para poder facilitar a los usuarios la planificación, exploración y gestión de actividades turísticas en diferentes destinos dentro de la ciudad de Loja.

El objetivo general de la aplicación es brindar información relevante y actualizada sobre lugares turísticos, restaurantes, monumentos históricos, actividades, etc.

El sistema le permitirá a los usuarios buscar destinos, ver información detallada, dejar o consultar recomendaciones de otros usuarios y establecer un itinerario según sus preferencias, y también incluirá un sistema de traducción en tiempo real para que el usuario tenga una mejor experiencia.
