## 🚀 Cómo Ver la Documentación

### Opción 1: HTML en Navegador (Recomendado)
```bash
# Windows
render.bat

# macOS/Linux
bash render.sh

# Luego abre index.html en tu navegador
```

### Opción 2: Vista Previa en Vivo
```bash
quarto preview index.qmd
```
Se abrirá automáticamente en el navegador y se actualizará cuando hagas cambios.

### Opción 3: Ver Directamente en Editor
Abre cualquier archivo `.qmd` en VS Code o tu editor favorito.
Son archivos Markdown, fáciles de leer.

### Opción 4: PDF
```bash
# Windows
quarto render index.qmd --to pdf

# macOS/Linux
quarto render index.qmd --to pdf
```
