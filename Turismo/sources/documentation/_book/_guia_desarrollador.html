6  Guía del Desarrollador

6.1 Introducción para Desarrolladores

Esta guía está dirigida a desarrolladores que deseen: - Entender la arquitectura interna del sistema - Contribuir con nuevas funcionalidades - Mantener y actualizar el código - Realizar debugging y testing

6.2 Stack Tecnológico Completo

6.2.1 Backend

  • Framework: Django 6.0.4
  • API: Django REST Framework (DRF)
  • Autenticación: djangorestframework-simplejwt
  • Documentación API: drf-spectacular
  • ORM: Django ORM
  • Base de Datos: SQLite
  • Base de Datos (Producción): PostgreSQL (recomendado)
  • Validación: Django Serializers
  • Testing: Django TestCase, pytest

  • Librería: React 18.3.1
  • Enrutamiento: React Router DOM 6.30.0
  • HTTP Client: Axios 1.9.0
  • CSS Framework: Tailwind CSS 3.4.17
  • Bundler: Vite 6.3.0
  • PostCSS: Para procesamiento de estilos
  • Testing: Vitest, React Testing Library

6.4 Conceptos Clave de Arquitectura

6.4.1 1. Models (Modelos de Datos)

Ubicación: apps/*/models.py

Los modelos definen la estructura de datos. Ejemplo:

from django.db import models

class AtractivoTuristico(models.Model):
    nombre = models.CharField(max_length=255)
    descripcion = models.TextField()
    latitud = models.FloatField()
    longitud = models.FloatField()
    canton = models.ForeignKey(
        Canton, 
        on_delete=models.CASCADE
    )
    estado = models.CharField(
        max_length=20,
        choices=EstadoAtractivo.choices
    )
    fecha_creacion = models.DateTimeField(auto_now_add=True)
    
    class Meta:
        ordering = ['-fecha_creacion']
        verbose_name_plural = "Atractivos Turísticos"
    
    def __str__(self):
        return self.nombre

Características: - Hereda de models.Model - Cada atributo es un campo - Relaciones via ForeignKey, ManyToManyField - Metadata en clase Meta - Método __str__ para representación

6.4.2 2. Serializers (Validación y Transformación)

Ubicación: apps/*/serializers.py

Serializadores convierten modelos a JSON y validan datos:

from rest_framework import serializers
from .models import AtractivoTuristico

class AtractivoSerializer(serializers.ModelSerializer):
    clasificaciones = serializers.StringRelatedField(
        many=True, 
        read_only=True
    )
    
    class Meta:
        model = AtractivoTuristico
        fields = [
            'id', 'nombre', 'descripcion',
            'latitud', 'longitud', 'estado',
            'clasificaciones', 'fecha_creacion'
        ]
        read_only_fields = ['id', 'fecha_creacion']
    
    def validate_nombre(self, value):
        if len(value) < 5:
            raise serializers.ValidationError(
                "El nombre debe tener mínimo 5 caracteres"
            )
        return value

Características: - Hereda de serializers.ModelSerializer - Especifica modelo y campos en Meta - Métodos validate_* para validación - Read-only fields para campos de solo lectura

6.4.3 3. Views (Endpoints HTTP)

Ubicación: apps/*/views.py

Las views manejan requests HTTP:

from rest_framework import viewsets, status
from rest_framework.decorators import action
from rest_framework.response import Response
from .models import AtractivoTuristico
from .serializers import AtractivoSerializer

class AtractivoViewSet(viewsets.ModelViewSet):
    queryset = AtractivoTuristico.objects.all()
    serializer_class = AtractivoSerializer
    
    def get_queryset(self):
        # Filtrar por cantón si se proporciona
        canton = self.request.query_params.get('canton')
        queryset = super().get_queryset()
        if canton:
            queryset = queryset.filter(canton_id=canton)
        return queryset
    
    @action(detail=True, methods=['post'])
    def enviar_revision(self, request, pk=None):
        """Cambiar estado a REVISION"""
        atractivo = self.get_object()
        atractivo.estado = 'REVISION'
        atractivo.save()
        return Response({
            'status': 'Atractivo enviado a revisión'
        })

Características: - ModelViewSet proporciona CRUD automático - get_queryset() para filtrado personalizado - Decorador @action para endpoints custom - Retorna respuestas JSON

6.4.4 4. Services (Lógica de Negocio)

Ubicación: apps/*/services.py

Los servicios contienen la lógica de negocio, separados de views:

from django.db import transaction
from .models import AtractivoTuristico

class AtractivoService:
    @staticmethod
    def crear_atractivo(datos):
        """Crear atractivo con validaciones de negocio"""
        try:
            atractivo = AtractivoTuristico.objects.create(**datos)
            return atractivo
        except Exception as e:
            raise AtractivoServiceException(str(e))
    
    @staticmethod
    def publicar_atractivo(atractivo_id):
        """Cambiar estado a PUBLICADO"""
        atractivo = AtractivoTuristico.objects.get(id=atractivo_id)
        atractivo.estado = 'PUBLICADO'
        atractivo.save()
        return atractivo
    
    @staticmethod
    def obtener_atractivos_por_canton(canton_id):
        """Obtener atractivos de un cantón"""
        return AtractivoTuristico.objects.filter(
            canton_id=canton_id,
            estado='PUBLICADO'
        )

Ventajas: - Reutilización de lógica - Testing más fácil - Cambios centralizados - Separación de responsabilidades

6.6.2 Páginas

Ubicación: src/pages/

// pages/AtractivesList.jsx
import React, { useState, useEffect } from 'react';
import { AtractiveCard } from '../components/AtractiveCard';
import { getAtractivos } from '../services/api';

export function AtractivesList() {
  const [atractivos, setAtractivos] = useState([]);
  const [loading, setLoading] = useState(true);
  
  useEffect(() => {
    const loadAtractivos = async () => {
      try {
        const data = await getAtractivos();
        setAtractivos(data);
      } catch (error) {
        console.error('Error:', error);
      } finally {
        setLoading(false);
      }
    };
    
    loadAtractivos();
  }, []);
  
  if (loading) return <div>Cargando...</div>;
  
  return (
    <div className="grid grid-cols-3 gap-4">
      {atractivos.map(att => (
        <AtractiveCard key={att.id} atractivo={att} />
      ))}
    </div>
  );
}

6.6.3 Servicios API

Ubicación: src/services/

// services/api.js
import axios from 'axios';

const API_URL = import.meta.env.VITE_API_URL;
const client = axios.create({ baseURL: API_URL });

// Interceptor para JWT
client.interceptors.request.use(config => {
  const token = localStorage.getItem('access_token');
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});

export async function getAtractivos(params = {}) {
  const response = await client.get('/atractivos/', { params });
  return response.data.data;
}

export async function createAtractivo(data) {
  const response = await client.post('/atractivos/', data);
  return response.data.data;
}

6.6.4 Context API (Estado Global)

Ubicación: src/contexts/

// contexts/AuthContext.jsx
import React, { createContext, useState } from 'react';

export const AuthContext = createContext();

export function AuthProvider({ children }) {
  const [user, setUser] = useState(null);
  const [token, setToken] = useState(localStorage.getItem('access_token'));
  
  const login = async (email, password) => {
    const response = await fetch(`${API_URL}/usuarios/login/`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ email, password })
    });
    
    const data = await response.json();
    setToken(data.data.access);
    setUser(data.data.usuario);
    localStorage.setItem('access_token', data.data.access);
  };
  
  return (
    <AuthContext.Provider value={{ user, token, login }}>
      {children}
    </AuthContext.Provider>
  );
}

6.7 Testing

6.7.1 Backend - Tests Unitarios

Ubicación: apps/*/tests.py

from django.test import TestCase
from rest_framework.test import APIClient
from .models import AtractivoTuristico

class AtractivoTestCase(TestCase):
    def setUp(self):
        self.client = APIClient()
        self.atractivo = AtractivoTuristico.objects.create(
            nombre="Test Atractivo",
            descripcion="Descripción test",
            latitud=-0.5,
            longitud=-78.5
        )
    
    def test_crear_atractivo(self):
        """Test para crear atractivo"""
        response = self.client.post('/api/atractivos/', {
            'nombre': 'Nuevo Atractivo',
            'descripcion': 'Descripción',
            'latitud': -0.5,
            'longitud': -78.5
        })
        self.assertEqual(response.status_code, 201)
    
    def test_listar_atractivos(self):
        """Test para listar atractivos"""
        response = self.client.get('/api/atractivos/')
        self.assertEqual(response.status_code, 200)
        self.assertGreater(len(response.data['data']), 0)

6.10 Performance y Optimización

6.10.1 Backend

  1. Índices en Base de Datos:
class AtractivoTuristico(models.Model):
    nombre = models.CharField(max_length=255, db_index=True)
    canton = models.ForeignKey(Canton, db_index=True)
  1. Queries Optimizadas:
# Mal (N+1 queries)
atractivos = AtractivoTuristico.objects.all()
for a in atractivos:
    print(a.canton.nombre)  # Query por cada uno

# Bien (Una query)
atractivos = AtractivoTuristico.objects.select_related('canton')
  1. Caché:
from django.views.decorators.cache import cache_page

@cache_page(60 * 15)  # Cache por 15 minutos
def get_atractivos(request):
    ...
