3  Guía de Instalación

3.1 Requisitos del Sistema

3.1.1 Software Requerido

  • Python 3.10 o superior
  • Node.js 16 o superior
  • npm o yarn
  • Git
  • SQLite (incluido en Python)
  • Navegador moderno (Chrome, Firefox, Safari, Edge)

3.1.2 Requisitos de Hardware

  • Procesador: Dual-core 2GHz o superior
  • RAM: Mínimo 2GB (4GB recomendado)
  • Almacenamiento: 500MB para instalación completa

3.1.3 Sistema Operativo

  • Windows 10/11
  • macOS 10.14+
  • Ubuntu 18.04+

3.2 Instalación del Backend (Django)

3.2.1 Paso 1: Clonar o Descargar el Repositorio

cd c:\ruta\a\tu\carpeta
git clone <url-repositorio>
cd Turismo-develop/Turismo

3.2.2 Paso 2: Crear Entorno Virtual

3.2.2.1 En Windows:

python -m venv venv
venv\Scripts\activate

3.2.2.2 En macOS/Linux:

python3 -m venv venv
source venv/bin/activate

3.2.3 Paso 3: Instalar Dependencias de Python

pip install --upgrade pip
pip install -r requirements.txt

Paquetes principales instalados: - Django 6.0.4 - Django REST Framework - djangorestframework-simplejwt - drf-spectacular - django-filters - python-decouple

3.2.4 Paso 4: Verificar Instalación

python manage.py --version

3.2.5 Paso 5: Ejecutar Migraciones (Base de Datos)

python manage.py migrate

Este comando: - Crea la estructura de tablas en SQLite - Aplica todas las migraciones pendientes - Inicializa la base de datos

3.2.6 Paso 6: Crear Superusuario (Administrador)

python manage.py createsuperuser

Se te pedirá: - Username: (tu nombre de usuario) - Email: (tu correo) - Password: (contraseña segura) - Password (again): (confirmar contraseña)

3.2.7 Paso 7: Verificar Estructura de Base de Datos

python manage.py dbshell

Dentro de SQLite:

.tables

Verás todas las tablas creadas.

3.2.8 Paso 8: Iniciar Servidor Django

python manage.py runserver

El servidor estará disponible en:

http://localhost:8000
Admin: http://localhost:8000/admin
API: http://localhost:8000/api

3.3 Instalación del Frontend (React)

3.3.1 Paso 1: Navegar a la Carpeta Frontend

cd templates/frontend_react

3.3.2 Paso 2: Instalar Dependencias de Node

npm install
# o si usas yarn:
yarn install

Paquetes principales instalados: - React 18.3.1 - React Router DOM 6.30.0 - Axios 1.9.0 - Tailwind CSS 3.4.17 - Vite 6.3.0

3.3.3 Paso 3: Configurar Variables de Entorno

Crear archivo .env en la carpeta frontend_react:

VITE_API_URL=http://localhost:8000/api
VITE_DEBUG=false

3.3.4 Paso 4: Verificar Instalación

npm --version
node --version

3.3.5 Paso 5: Iniciar Servidor de Desarrollo

npm run dev

El frontend estará disponible en:

http://localhost:5173

3.3.6 Paso 6: (Opcional) Compilar para Producción

npm run build

Crea carpeta dist/ con archivos optimizados.

3.5 Verificación de Instalación Completa

Ejecutar en dos terminales simultaneamente:

3.5.1 Terminal 1 (Backend):

cd Turismo-develop/Turismo
source venv/bin/activate  # En Windows: venv\Scripts\activate
python manage.py runserver

Verifica que muestre:

Starting development server at http://127.0.0.1:8000/
Quit the server with CTRL-BREAK.

3.5.2 Terminal 2 (Frontend):

cd Turismo-develop/Turismo/templates/frontend_react
npm run dev

Verifica que muestre:

VITE v6.x.x  ready in xxx ms

➜  Local:   http://localhost:5173/

3.5.3 Acceso a Aplicación:

  • Aplicación: http://localhost:5173
  • API: http://localhost:8000/api
  • Admin Django: http://localhost:8000/admin

3.6 Troubleshooting

3.6.1 Problema: “ModuleNotFoundError” en Python

Solución:

pip install -r requirements.txt

3.6.2 Problema: “Cannot find module” en Node

Solución:

rm -rf node_modules package-lock.json
npm install

3.6.3 Problema: Puerto 8000 o 5173 en uso

Cambiar puerto Django:

python manage.py runserver 8001

Cambiar puerto Vite:

npm run dev -- --port 5174

3.6.4 Problema: Base de datos corrupta

Solución (pierde datos):

rm db.sqlite3
python manage.py migrate
python manage.py createsuperuser

3.6.5 Problema: Errores de CORS

Verificar config/settings.py tenga configurado CORS correctamente:

CORS_ALLOWED_ORIGINS = [
    "http://localhost:5173",
    "http://localhost:3000",
]

3.7 Comandos Útiles

3.7.1 Backend (Django)

# Crear nueva migración
python manage.py makemigrations

# Aplicar migraciones
python manage.py migrate

# Crear superusuario
python manage.py createsuperuser

# Ejecutar tests
python manage.py test

# Limpiar base de datos
python manage.py flush

3.7.2 Frontend (React)

# Iniciar desarrollo
npm run dev

# Build para producción
npm run build

# Ver build en producción local
npm run preview
